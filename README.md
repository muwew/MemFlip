#MemFlip

*A final year project by Marvell Ung*

MemFlip is a web-app based game developed using React.js, TypeScript, and Tailwind.css as the frontend and Node.js as the backend. It uses Supabase as its database. It has been deployed on Vercel.

##Gameplay
Memflip consists of 5 stages of gameplay:

###**Stage 1: Card Flipping**

1. Image pair shown for a set time
2. Images flipped and hidden
3. **Task**: Memorize and match the most pairs before time ends
   
###**Stage 2: Name Recognition**

1. Images and their names shown for a set time
2. **Task**: Memorize all image-name pairs
3. Images shuffled, players answer the names

###**Stage 3: Mass Memorisation**

1. A big image with labels shown for a set time
2. **Task**: Memorize as many labels as possible

###**Stage 4: Sequence Memorisation**

1. Images shown in sequence
2. **Task**: Memorize the sequence and reproduce as the answer

###**Stage 5: Sliding Tile Puzzle**

1. An image split and shuffled in a grid
2. **Task**: Reshuffle and reproduce the original image
